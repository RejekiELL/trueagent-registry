01

The problem

Agent IDs are being rented out for a few dollars so strangers can farm Agent-ID-gated launches with someone else's identity. Holding an Agent ID proves an identity exists — it does not prove who operates it.

02

The signal

A holder pledges on-chain — “I operate this Agent ID myself” — and other holders endorse operators they trust. Any launchpad or gated mint can query one function before allocating a per-Agent-ID quota:

isSelfOperated(address) → bool
03

Nothing to buy

No token. No mint. No sale. The registry holds no funds and has no owner or admin functions. A pledge also dies automatically if the address stops holding its Agent ID.

04

For projects

Call isSelfOperated(user) on the registry before granting a per-Agent-ID allocation. Rented IDs that never pledge carry no trust signal. Source is verified on Sourcify (exact match) and public on GitHub.

TrueAgent is an independent community project, not affiliated with Binance. It never asks for seed phrases, private keys, pairing codes, or login QR scans — pledging is a normal transaction you confirm in your own wallet.
